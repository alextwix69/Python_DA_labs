# Лабораторная работа № 2 — пункт 3

## Метод и материалы

Для Iris использованы все четыре числовых признака: `sepal length (cm)`, `sepal width (cm)`, `petal length (cm)`, `petal width (cm)`. Для бейсболистов использованы `Height(inches)`, `Weight(pounds)`, `Age` и категориальная `Position`. Коды `Position` преобразованы в исходные английские названия (`Starting_Pitcher`, `Catcher` и др.), затем закодированы one-hot. Числовые признаки стандартизованы. Такая же подготовка применялась в пункте 2. Видовые метки Iris не использовались.

PCA обучен на всех подготовленных признаках каждого набора. На плоскости показаны первые две главные компоненты. Точность двумерного представления оценена по накопленной доле объяснённой дисперсии и по доле вариации, восстановленной из первых двух компонент: эти величины здесь совпадают.

## Iris

| Показатель | Значение |
|---|---:|
| Доля дисперсии PC1 | 73,0% |
| Доля дисперсии PC2 | 22,9% |
| Доля дисперсии PC1 + PC2 | **95,8%** |
| Число компонент для сохранения ≥ 90% дисперсии | **2** |

PC1 задаётся прежде всего признаками `petal length (cm)` (+0,58), `petal width (cm)` (+0,57) и `sepal length (cm)` (+0,52). У `sepal width (cm)` вклад в PC1 имеет противоположный знак (−0,27). PC2 в основном связана с `sepal width (cm)` (+0,92), а также с `sepal length (cm)` (+0,38). Знак компоненты можно целиком изменить без изменения результата PCA; содержательный вывод определяется относительными знаками и величинами нагрузок.

На плоскости отчётливо видны **две крупные области**: компактная слева и более растянутая справа. Внутри правой области точки частично перекрываются; по PCA нельзя уверенно отделить в ней третью группу. Поэтому по одному этому графику предположительное число кластеров — **2**, с возможным делением второй области на две. Вывод о третьей группе из пункта 2 остаётся гипотезой для следующих методов. Двумерная проекция достаточно точна по доле дисперсии, однако высокий процент сам по себе не доказывает существование кластеров.

## Бейсболисты

| Показатель | Значение |
|---|---:|
| Доля дисперсии PC1 | 40,9% |
| Доля дисперсии PC2 | 27,4% |
| Доля дисперсии PC1 + PC2 | **68,3%** |
| Число компонент для сохранения ≥ 80% / 90% / 95% дисперсии | **4 / 5 / 7** |

PC1 в основном отражает совместное увеличение `Height(inches)` (+0,69) и `Weight(pounds)` (+0,71). PC2 почти полностью связана с `Age` (+0,95); вклад `Height(inches)` в неё отрицательный (−0,27). Коэффициенты категорий `Position` на первых двух компонентах малы по сравнению с числовыми признаками. Следовательно, положение точки на двумерном графике плохо передаёт различия между игровыми позициями; часть информации о `Position` остаётся в последующих компонентах.

Проекция образует преимущественно непрерывное, сильно перекрывающееся облако. Уверенно определить число кластеров по ней **нельзя**. Если нужна рабочая гипотеза для дальнейшей проверки, из пункта 2 можно взять **2 группы**, но PCA не даёт для неё самостоятельного сильного подтверждения. Две компоненты сохраняют лишь 68,3% дисперсии, поэтому отсутствие чётких групп на плоскости не исключает структуры в оставшихся измерениях.

## Сопоставление

Для Iris двумерный PCA сохраняет почти всю вариацию и показывает устойчивое крупное разделение на две области. Иерархическая кластеризация из пункта 2 допускает более подробное деление на три группы. Для бейсболистов PCA менее точен как двумерное представление и не выявляет убедительных отдельных областей; предположения о 2 или 3 группах из пункта 2 требуют дальнейшей проверки.
