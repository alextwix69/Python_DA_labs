# Лабораторная работа № 2 — пункт 2

## Данные и метод

Иерархическая кластеризация проведена для 150 наблюдений Iris и 1034 наблюдений бейсболистов. Для Iris использованы все четыре признака с исходными именами: `sepal length (cm)`, `sepal width (cm)`, `petal length (cm)`, `petal width (cm)`. Для бейсболистов использованы `Height(inches)`, `Weight(pounds)`, `Age` и категориальная `Position`. Коды `Position` преобразованы в английские названия из исходных данных (`Starting_Pitcher`, `Catcher` и т. д.), затем применено one-hot кодирование. Числовые признаки обоих наборов стандартизованы. Известные виды Iris в кластеризации не использованы.

Сравнены четыре расстояния: евклидово, манхэттенское, Чебышёва и косинусное. Для каждого рассмотрены одиночная, полная и невзвешенная средняя связь. Невзвешенная центроидная связь и метод Уорда применены только с евклидовым расстоянием: эти методы требуют евклидовой геометрии. Итого проверено **14 допустимых сочетаний** для каждого набора. Для каждого дерева рассмотрены разрезы на 2–8 кластеров.

Качество разрезов сравнено по коэффициенту силуэта и размерам групп; дополнительно рассчитана копенетическая корреляция между исходными расстояниями и расстояниями дерева. Для Iris силуэт рассчитан на всех 150 наблюдениях; для бейсболистов — на фиксированной случайной подвыборке 500 наблюдений (`seed=42`). При выборе показательного удачного результата исключены разрезы с группой меньше 5% исходной выборки. Значения силуэта, полученные для разных метрик, сравниваются с оговоркой: каждая метрика задаёт своё понятие близости.

## Iris

| Конфигурация | Число групп | Размеры групп | Силуэт | Копенетическая корреляция |
|---|---:|---|---:|---:|
| Косинусное расстояние, полная связь | 3 | 69, 49, 32 | 0,738 | 0,783 |
| Косинусное расстояние, одиночная связь | 2 | 149, 1 | −0,116 | 0,872 |
| Евклидово расстояние, метод Уорда | 2 | 101, 49 | 0,577 | 0,823 |
| Евклидово расстояние, метод Уорда | 3 | 71, 49, 30 | 0,447 | 0,823 |

Косинусное расстояние с полной связью даёт наиболее отчётливое из рассмотренных сбалансированных разделений на **3 группы**. На графике расстояний слияния переход от 3 групп к 2 сопровождается заметным ростом высоты слияния (примерно с 1,20 до 1,99). Это поддерживает разрез на три группы.

Одиночная связь с той же мерой расстояния даёт пример неудачного результата: при двух группах одна из них содержит только одну точку. Несмотря на более высокую копенетическую корреляцию, такой разрез слабо описывает структуру всей выборки. Евклидов метод Уорда подтверждает более крупное разделение примерно на группы 100 и 50; при разрезе на три группы крупная группа делится на две (71 и 30). Следовательно, для Iris **предположительно 3 кластера**, но устойчивее всего выделяется одна группа относительно остальных; выбор между 2 и 3 зависит от расстояния и требуемой детализации.

## Бейсболисты

| Конфигурация | Число групп | Размеры групп | Силуэт | Копенетическая корреляция |
|---|---:|---|---:|---:|
| Косинусное расстояние, полная связь | 3 | 380, 365, 289 | 0,322 | 0,542 |
| Косинусное расстояние, одиночная связь | 8 | 1010, 7, 7, 5, 2, 1, 1, 1 | −0,329 | 0,202 |
| Евклидово расстояние, метод Уорда | 2 | 677, 357 | 0,206 | 0,456 |
| Евклидово расстояние, метод Уорда | 3 | 677, 195, 162 | 0,190 | 0,456 |

Косинусное расстояние с полной связью даёт три достаточно равные группы и наибольший силуэт среди сбалансированных вариантов. Однако на графике высот слияния **нет резкого скачка именно при переходе от 3 групп к 2**: высоты меняются довольно плавно. Евклидов метод Уорда даёт небольшое предпочтение двум группам. Одиночная связь формирует «цепочку»: 1010 объектов оказываются в одной группе, а остальные выделяются в несколько малых групп и одиночные наблюдения. Это явный пример плохого разделения.

Для бейсболистов **2 группы — осторожная предварительная оценка**; вариант с 3 группами также заслуживает проверки на следующих этапах. Вывод менее устойчив, чем для Iris, поскольку зависит от метрики и не сопровождается отчётливым разрывом высот слияния. Силуэт здесь ниже, чем у удачного варианта Iris, что согласуется с сильным перекрытием точек на исходном 3D-графике.
